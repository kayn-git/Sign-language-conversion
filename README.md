# Sign-language-conversion
This project utilizes Convolutional Neural Networks (CNNs) and OpenCV to recognize hand gestures representing sign language and converts them into both text and speech outputs.​

🔧 Features
Real-Time Gesture Recognition: Captures and processes hand gestures in real-time using a webcam.

CNN-Based Classification: Employs a trained CNN model to accurately classify hand gestures corresponding to sign language alphabets.

Text Conversion: Translates recognized gestures into textual representation.

Speech Output: Utilizes text-to-speech libraries to vocalize the translated text, facilitating verbal communication.​

🚀 Technologies Used
Python: Primary programming language for implementation.

OpenCV: For image capture and processing.

TensorFlow/Keras: To build and train the CNN model.

Text-to-Speech Library: Such as pyttsx3 or gTTS for speech synthesis.​

📁 Repository Structure
dataset/: Contains the dataset of hand gesture images used for training.

model/: Includes the trained CNN model files.

app.py: Main application script to run the gesture recognition and conversion.

requirements.txt: Lists all the dependencies required to run the project.​
